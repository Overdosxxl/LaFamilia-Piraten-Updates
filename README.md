# La Familia Piraten Updates

Public distribution metadata for Fabric 1.21.1 launcher.

- `news/news.json` – launcher news feed
- `mods/manifest.json` – signed or hash-verified mod downloads (add later)
- `releases/channel.json` – beta/stable launcher version metadata

Never commit credentials or private server tokens. Only distribute mods for which redistribution is allowed. Store large mod JARs as GitHub Release assets where practical.

The JSON files currently contain no real content and are not yet connected to the launcher.
